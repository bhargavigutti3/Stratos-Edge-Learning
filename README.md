# Stratos Edge Learning Website
A responsive multi-page educational training website built using HTML, CSS, and JavaScript.

## 📌 About the Project
Stratos Edge Learning is a training website designed to present industry-focused courses in Web Development, Data Science, and AI.
The website provides information about the organization, available services, and contact details through a clean and responsive interface.

## 🚀 Features
- Responsive multi-page website
- Home page with course-focused introduction
- About page with mission, approach, and team information
- Services page with training programs
- Contact page with contact form
- Client-side form validation
- Responsive navigation menu
- Mobile-friendly design
- Interactive hover effects
- Clean and modern user interface

## 🛠️ Technologies Used
- HTML5
- CSS
- JavaScript
- GitHub
